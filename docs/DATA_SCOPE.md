# Data scope and privacy

The repository includes only compressed aggregate summaries, their manifests,
and one aggregate 10 by 10 HBN-derived correlation geometry.

It does not include participant identifiers, participant-level feature rows,
private split manifests, raw imaging data, or raw phenotype data. The observed
HBN analysis is explicitly labeled as a model-based exploratory application and
is not used as validation of the Gaussian model.

Reproduction from raw HBN inputs is an optional external-data workflow subject
to the upstream dataset's access, citation, and usage requirements. Absence of
those external inputs does not prevent frozen reproduction or smoke validation.
